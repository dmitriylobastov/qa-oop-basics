# qa-oop-basics

Учебный проект по ООП для автоматизации тестирования.

## Что внутри
- `PaymentCard` — класс с инкапсуляцией (приватные поля, валидация в конструкторе).
- `Main` — демонстрация: пополнение, успешное и неуспешное списание.

## Как запустить
`mvn compile exec:java` или через IDE — класс `ru.stepup.payments.Main`.
